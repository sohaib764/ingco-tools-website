# Ingco Tools Website

A web-based e-commerce project developed for showcasing and managing INGCO tools and products. The project includes product browsing, shopping cart functionality, checkout flow, and database integration.

## 🚀 Features

* Product listing and product details
* Shopping cart
* Checkout system
* Product management
* Database connectivity
* Responsive web interface
* PHP-based backend
* MySQL database integration

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap

## 📂 Project Structure

The project contains different pages and components for handling products, cart functionality, checkout, database connection, and website styling.

## 💻 How to Run

### Requirements

* XAMPP or another PHP development environment
* Apache
* MySQL
* Web browser

### Installation

1. Download or clone this repository.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** from XAMPP.
4. Create a MySQL database named:

```text
product_card
```

5. Import the project's SQL database file into MySQL/phpMyAdmin.
6. Check the database connection settings in `config.php`.
7. Open the project in your browser through:

```text
http://localhost/ingco-tools-website/
```
